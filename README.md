# MIPTV Sales & Inventory

Standalone sales, purchasing and inventory management platform.

## Modules
- Dashboard, address book and tasks
- Customers, prospects, suppliers and sales leads
- Inventory items, transfers, kitting and bundling, categories, attributes, locations and zones
- Estimates, purchase orders, sales orders and sales invoices
- Sales, purchase, inventory and financial reports
- CSV import/export for customers, suppliers, inventory, sales orders and invoices (including line items)
- Administration, user roles and permissions
- Arabic and English user interface

## Planned stack
Next.js, TypeScript, PostgreSQL (Neon), and Vercel. No secrets should be committed to GitHub.

## Important
Development is in progress. This README is the initial project specification, not a completed application.
